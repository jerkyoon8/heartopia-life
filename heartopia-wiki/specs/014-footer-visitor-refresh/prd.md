# PRD: 공통 푸터 및 접속자 통계 재배치

## 1. Summary

### Problem

현재 공통 푸터는 긴 안내 문구가 중앙에만 모여 있어 정보 구조가 약하고, 주간·오늘 접속자 수는 상단 내비게이션의 오른쪽 공간을 차지한다. 이 공간은 이후 시간·날씨 정보에 사용될 예정이다.

### Proposed Solution

기존 사이트의 밝고 부드러운 색상 체계를 유지하면서 공통 푸터를 브랜드 소개, 이용 안내, 문의 링크, 접속자 통계, 저작권 안내가 구분되는 반응형 구조로 재설계한다. 헤더의 접속자 통계는 제거하고 같은 서버 데이터를 푸터 하단 상태 영역에 표시한다.

### Success Criteria

- 모든 공통 푸터 사용 페이지에서 동일한 새 푸터가 보인다.
- 주간·오늘 접속자 수가 푸터에 표시되고 헤더에서는 사라진다.
- 데스크톱과 모바일에서 정보가 겹치거나 가로 스크롤이 생기지 않는다.
- 밝은 테마와 어두운 테마에서 텍스트 및 링크 대비가 유지된다.

## 2. Users And Use Cases

### Primary Users

- 하토피아 정보를 탐색하는 데스크톱·모바일 방문자
- 문의, 개인정보 처리방침, 서비스 안내를 찾는 방문자

### User Stories

- As a 방문자, I want to 푸터에서 사이트 성격과 주요 안내를 빠르게 확인, so that 필요한 링크로 쉽게 이동할 수 있다.
- As a 방문자, I want to 오늘과 주간 접속자 수를 하단에서 확인, so that 상단 탐색에 방해받지 않고 서비스 활동성을 알 수 있다.
- As a 운영자, I want to 상단 우측 공간을 비워 두기, so that 추후 시간·날씨 정보를 배치할 수 있다.

## 3. Functional Scope

### In Scope

- 공통 푸터의 HTML 정보 구조 및 스타일 개편
- 기존 문의, 문의 게시판, 개인정보 처리방침 링크 유지·정리
- 주간·오늘 접속자 통계를 헤더에서 푸터로 이동
- 밝은/어두운 테마 및 반응형 레이아웃 지원
- 공통 CSS 캐시 버전 갱신

### Out Of Scope

- 시간·날씨 기능 구현
- 접속자 집계 방식 또는 데이터베이스 변경
- 새 후원, 개발자 프로필, 외부 SNS 링크 추가
- 기존 페이지별 본문 디자인 변경

## 4. Acceptance Criteria

- 푸터는 서비스 소개, 바로가기/운영 안내, 하단 법적 고지와 접속자 통계를 시각적으로 구분한다.
- 기존 이메일, 문의 게시판, 개인정보 처리방침에 접근할 수 있다.
- `weeklyVisitors`와 `todayVisitors`가 제공될 때 각각 쉼표 형식으로 표시된다.
- 접속자 데이터가 없을 때 통계 영역은 렌더링되지 않고 레이아웃은 정상 유지된다.
- 헤더에는 기존 접속자 카운터 마크업과 전용 스타일이 남지 않는다.
- 768px 이하에서는 푸터 열과 하단 영역이 자연스럽게 세로 배치된다.
- 기존 저작권·비공식 팬사이트 고지의 의미가 유지된다.

## 5. Constraints

- Tech: Spring Boot, Thymeleaf, Bootstrap, Font Awesome, 공통 `common.css`
- Time: 이번 변경에서는 정적 레이아웃과 기존 모델 데이터 재사용만 수행
- Data: `GlobalControllerAdvice`가 제공하는 `weeklyVisitors`, `todayVisitors` 재사용
- External Dependencies: 새 외부 라이브러리나 API 없음

## 6. Risks

- 공통 프래그먼트 변경으로 여러 페이지에 동시에 영향을 줌: 공통 CSS 범위를 `.site-footer` 아래로 제한하고 대표 페이지를 렌더링해 확인한다.
- 헤더 내부 중복 스타일과 공통 스타일이 충돌할 수 있음: 기존 `.visitor-counter` 정의를 함께 제거하고 푸터 전용 클래스명을 사용한다.
- 푸터가 지나치게 커질 수 있음: 기존 정보와 실제 동작하는 링크만 사용하고 장식 요소 수를 제한한다.
