# PRD: 도감 시간 필터 카드·표 결과 일치

## 1. Summary

### Problem

곤충과 새 도감의 표 보기 행에 등장 시간 데이터 속성이 없어, 시간 범위를 선택해도 표에서는 시간 조건이 적용되지 않은 항목이 노출된다. 예를 들어 비 오는 날 `6~12`시를 선택했을 때 `0~6 / 18~24`, `0~6 / 12~24`, `12~24` 항목이 함께 보인다.

### Proposed Solution

곤충과 새 도감의 표 행에도 카드와 동일한 등장 시간 값을 제공한다. 공통 시간 필터가 카드 보기와 표 보기에 같은 입력을 사용하도록 맞춘다.

### Success Criteria

- 곤충과 새 도감에서 동일 조건의 카드 보기와 표 보기 결과가 일치한다.
- `6~12` 선택 시 경계만 맞닿는 `0~6` 및 `12~24` 구간은 제외된다.
- 복수 등장 구간 중 하나라도 실제로 겹치면 해당 항목은 포함된다.

## 2. Users And Use Cases

### Primary Users

- 날씨와 등장 시간을 조합해 수집 대상을 찾는 도감 사용자

### User Stories

- 도감 사용자로서 보기 방식을 바꾸어도 같은 필터 결과를 보고 싶다.
- 도감 사용자로서 선택한 시간에 실제로 등장하는 생물만 확인하고 싶다.

## 3. Functional Scope

### In Scope

- 곤충 도감 표 행의 등장 시간 데이터 연결
- 새 도감 표 행의 등장 시간 데이터 연결
- 카드·표 시간 데이터 연결에 대한 회귀 검증

### Out Of Scope

- 등장 시간 원본 데이터 변경
- 시간 선택 UI 또는 시간 구간 겹침 규칙 변경
- 물고기 및 다른 도감의 필터 UI 개편

## 4. Acceptance Criteria

- 곤충과 새의 모든 표 행에 해당 생물의 `time` 값이 `data-time`으로 렌더링된다.
- 날씨 `비`, 시간 `6~12` 조건에서 황금귀신사슴벌레, 이색무당벌레, 흰올빼미가 시간 조건 때문에 제외된다.
- `상시 포함` 동작은 기존과 동일하다.
- 물고기 도감의 기존 시간 필터 동작은 유지된다.

## 5. Constraints

- Tech: Spring Boot 3.4.2, Thymeleaf, Vanilla JS 공통 `WikiFilter`
- Time: 현재 버그 수정 범위로 제한
- Data: DB 스키마 및 도감 데이터 변경 없음
- External Dependencies: 없음

## 6. Risks

- 카드와 표의 데이터 속성이 다시 달라질 수 있음: 템플릿 회귀 테스트로 필수 속성을 검증한다.
