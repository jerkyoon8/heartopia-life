# PRD: 헤더 도감 메가 메뉴 확장

## 1. Summary

### Problem

현재 헤더의 `컬렉션` 메뉴는 도감 4종만 보여 주어 취미와 기타 정보 페이지를 빠르게 찾을 수 없다.

### Proposed Solution

상단 메뉴명을 `도감`으로 바꾸고, 마우스를 올리면 `도감`, `취미`, `기타정보` 세 구역과 기존 유효 페이지 링크를 한 번에 보여 주는 메가 메뉴로 확장한다.

### Success Criteria

- 상단 메뉴에 `도감`이 표시되고 기존 `컬렉션` 문구는 표시되지 않는다.
- 도감에 마우스를 올리면 세 구역이 동시에 표시된다.
- 각 구역의 모든 항목이 실제 페이지로 이동하는 링크다.

## 2. Users And Use Cases

### Primary Users

- 데스크톱에서 원하는 도감·취미·정보 페이지를 빠르게 찾는 방문자

### User Stories

- As a 방문자, I want to 도감 메뉴 하나에서 전체 정보 분류를 확인하고 클릭하고 싶다, so that 원하는 페이지로 바로 이동할 수 있다.

## 3. Functional Scope

### In Scope

- `컬렉션` 메뉴명을 `도감`으로 변경
- 데스크톱 hover 메가 메뉴를 세 열로 구성
- 도감: 물고기, 곤충, 새, 동물
- 취미: 요리, 작물, 꽃, 채집물
- 기타정보: 주민들, 모래 조각, 바다 청소, 반려동물

### Out Of Scope

- 신규 페이지 또는 라우트 생성
- 모바일 전용 메가 메뉴 동작 변경
- 날씨·시간 영역 변경

## 4. Acceptance Criteria

- `도감` hover 상태에서 메뉴가 열리고 메가 메뉴 위로 포인터를 옮겨도 닫히지 않는다.
- 세 구역 제목과 12개 링크가 표시된다.
- 모든 링크가 현재 존재하는 Thymeleaf 라우트를 사용한다.
- 기존 헤더 날씨 UI와 모바일 헤더 너비를 깨뜨리지 않는다.

## 5. Constraints

- Tech: 기존 Thymeleaf 공통 헤더와 내부 CSS를 유지한다.
- Data: 데이터 및 DB 변경 없음
- External Dependencies: 없음

## 6. Risks

- 링크가 많아져 메뉴가 복잡해질 수 있음: 세 열과 명확한 구역 제목으로 구분한다.
- 기존 템플릿 회귀 테스트와 충돌: 새 탐색 구조에 맞게 테스트를 갱신한다.

## 7. Open Questions

- 없음. 기존에 사용하던 유효한 세 구역 링크 구성을 복원하되 명칭을 요청대로 변경한다.
