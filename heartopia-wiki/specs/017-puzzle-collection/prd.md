# PRD: 퍼즐 도감

## 1. Summary

### Problem

퍼즐 이미지와 한국어 퍼즐 정보가 서로 다른 파일에 분리되어 있어 웹에서 함께 확인할 수 없다. 기존 일반·동물 퍼즐 80개에 고래 탐사 시즌 퍼즐 이미지·이름·가격 10개가 추가로 확보되었다.

### Proposed Solution

엑셀의 도감순·분류·한국어 이름·크기·획득처·구매가격을 현재 이미지 90개와 매칭한다. 매칭된 항목을 로컬 DB와 정적 이미지로 구성하고, 위키의 “기타 정보” 영역에 검색·필터 가능한 퍼즐 도감으로 제공한다.

### Success Criteria

- 이미지 90개가 서로 다른 한국어 퍼즐 90개와 중복·누락 없이 연결된다.
- `/wiki/others/puzzles`에서 90개 퍼즐의 이미지, 이름, 분류, 크기, 획득처, 구매가격을 확인할 수 있다.
- 메인 “기타 정보”와 상단 기타정보 메뉴에서 퍼즐 도감으로 이동할 수 있다.

## 2. Users And Use Cases

### Primary Users

- 보유하지 않은 퍼즐의 이름과 획득처를 찾는 두근두근타운 이용자
- 퍼즐 데이터를 검수·추가하는 사이트 운영자

### User Stories

- As a 이용자, I want to 퍼즐 이미지와 한국어 이름을 함께 보고 싶다, so that 게임 화면의 퍼즐을 빠르게 식별할 수 있다.
- As a 이용자, I want to 이름·분류·크기로 목록을 거르고 싶다, so that 원하는 퍼즐의 획득처를 바로 확인할 수 있다.

## 3. Functional Scope

### In Scope

- 이미지가 확보된 기존 80개와 고래 탐사 시즌 10개 항목 매칭
- 한국어 이름을 포함한 최종 CSV 생성
- `puzzle_collections` 테이블 및 90개 초기 데이터 SQL
- 퍼즐 이미지 정적 리소스 추가
- 퍼즐 목록 페이지, 이름 검색, 분류·크기 필터
- 메인 기타 정보 카드와 헤더 메뉴 링크
- 핵심 매칭·화면 연결 테스트

### Out Of Scope

- 이미지가 없는 일화 퍼즐 2개와 나머지 시즌 한정 퍼즐 16개 노출
- 관리자 CRUD 화면
- 체크리스트/로그인 사용자 동기화
- 운영 서버 DB 반영과 배포

## 4. Acceptance Criteria

- 이미지 ID 1~80이 모두 한 번씩 사용된다.
- 엑셀 도감순 1~56과 59~82가 각각 올바른 이미지에 대응한다.
- 목록은 도감순 기준으로 정렬되고 빈 이미지 경로가 없다.
- 검색어가 이름에 포함된 퍼즐만 표시된다.
- 일반·동물 분류와 1x1~4x4 크기 필터가 동작한다.
- 빈 결과일 때 안내 문구가 표시된다.
- 로컬 DB에 SQL 적용 후 퍼즐 개수 조회 결과가 90이다.

## 5. Constraints

- Tech: Java 17, Spring Boot, Thymeleaf, MyBatis, MySQL 8.0
- Time: 이번 작업에서 로컬 MVP까지 구현
- Data: 엑셀을 한국어 정보의 기준으로 사용하고 TheGamer 이미지 ID를 이미지 기준으로 사용
- External Dependencies: 저장소 외부 원본 퍼즐 이미지 자료

## 6. Risks

- 엑셀 도감순과 이미지 ID가 57번부터 어긋남: 영문 퍼즐명과 동물별 순서를 함께 확인한 명시적 매핑을 사용한다.
- 현재 이미지가 90개임: 이미지 없는 18개는 이번 페이지에서 제외하고 추후 추가 대상으로 남긴다.
- SQL 자동 초기화가 꺼져 있음: 로컬 DB에 SQL을 별도로 실행하고 검증 쿼리를 제공한다.

## 7. Open Questions

- 없음. 현재는 이미지까지 완성된 90개만 노출한다.

## 8. 고래 시즌 분류

- `시즌한정` 대신 실제 이벤트명인 `고래 탐사 시즌`을 퍼즐 분류값으로 사용한다.
- 99~108번의 분류는 `고래 탐사 시즌`으로 저장한다.
- 99~108번 획득처는 `고래 탐사 시즌-트렌드 상점`, 구매가격은 숫자 뒤에 `토큰`을 붙여 표시한다.
- 이용자는 기존 분류 필터에서 `고래 탐사 시즌` 퍼즐만 확인할 수 있어야 한다.
