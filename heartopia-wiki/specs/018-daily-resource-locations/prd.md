# PRD: 일일 자원 위치

## 1. Summary

### Problem

형광석과 그자리 참나무의 일일 위치를 이용자가 사이트에서 바로 확인할 수 없고, 운영자가 미래 위치를 미리 등록해 오전 6시에 자동 전환할 관리 수단도 없다.

### Proposed Solution

공통 헤더 시계 왼쪽에 현재 게임 날짜의 형광석·그자리 참나무 위치를 표시한다. 관리자는 전용 페이지에서 날짜별 위치를 미리 등록·수정·삭제하며, 시스템은 Asia/Seoul 오전 6시를 게임 날짜 경계로 사용한다.

### Success Criteria

- 모든 공통 헤더에서 현재 적용 중인 형광석·그자리 참나무 위치를 확인할 수 있다.
- 오전 6시가 되면 페이지를 새로 열거나 열린 페이지의 자동 갱신을 통해 다음 예약 값으로 바뀐다.
- 관리자가 오늘 및 미래 날짜의 위치를 등록·수정·삭제할 수 있다.

## 2. Users And Use Cases

### Primary Users

- 오늘의 형광석과 그자리 참나무 위치를 빠르게 확인하려는 이용자
- 여러 날짜의 위치를 미리 기록하려는 사이트 관리자

### User Stories

- As a 이용자, I want to 시계 옆에서 오늘의 두 자원 위치를 보고 싶다, so that 별도 페이지를 열지 않고 목적지로 이동할 수 있다.
- As an 관리자, I want to 날짜별 위치를 미리 등록하고 수정하고 싶다, so that 오전 6시마다 수동으로 사이트를 갱신하지 않아도 된다.

## 3. Functional Scope

### In Scope

- 날짜별 형광석·그자리 참나무 위치 저장 테이블
- 위치 유형 `N번 집 앞` 또는 `유적`만 허용하는 입력 검증
- 관리자 전용 등록·수정·삭제 페이지
- 헤더 시계 왼쪽의 현재 위치 표시
- Asia/Seoul 오전 6시 기준 게임 날짜 계산
- 열린 페이지에서 오전 6시 경계가 바뀌면 현재 위치 재조회

### Out Of Scope

- 일반 사용자의 위치 제보·투표
- 위치 이력 공개 페이지
- 지도 좌표나 지도 핀 연결
- 알림·푸시 메시지
- 날짜 자체를 공개 헤더에 표시

## 4. Acceptance Criteria

- `7월 30일` 예약은 Asia/Seoul 기준 `7월 30일 06:00`부터 `7월 31일 05:59:59`까지 적용된다.
- 공개 헤더에는 날짜 없이 두 자원명과 현재 위치만 표시된다.
- 집 위치는 양의 정수 집 번호와 `집 앞` 문구로 표시되며, 다른 자유문구는 저장할 수 없다.
- `유적`을 선택하면 집 번호 없이 `유적`으로 표시된다.
- 현재 게임 날짜의 데이터가 없으면 이전 날짜 값을 재사용하지 않고 `위치 정보 없음`을 표시한다.
- 관리자 URL과 변경 요청은 `ROLE_ADMIN`만 접근할 수 있다.
- 같은 게임 날짜에는 한 행만 존재하며 재등록은 해당 날짜 데이터를 수정한다.

## 5. Constraints

- Tech: Java 17, Spring Boot, Thymeleaf, MyBatis, MySQL 8.0, Vanilla JS
- Time: 이번 작업에서 로컬 구현과 검증까지
- Data: 날짜별로 형광석·그자리 참나무 위치를 한 행에 저장
- External Dependencies: 없음

## 6. Risks

- 서버·브라우저 시간 차이: 서버가 반환한 Asia/Seoul 시각을 기준으로 클라이언트 갱신 시점을 계산한다.
- 헤더 공간 부족: 데스크톱에서는 시계 왼쪽에 표시하고 좁은 화면에서는 간결한 형태로 줄인다.
- 예약 누락 시 오래된 정보 노출: 이전 값 폴백 없이 명시적인 빈 상태를 표시한다.
- SQL 자동 실행이 꺼져 있음: 애플리케이션 실행 전에 로컬 DB에 생성 SQL을 별도로 적용한다.

## 7. Open Questions

- 없음.

## 8. Resolved Decisions

- 공개 화면에는 날짜를 표시하지 않는다.
- 관리자 입력은 헤더 인라인 편집이 아니라 별도 관리자 페이지에서 처리한다.
- 위치 선택지는 `N번 집 앞`과 `유적`뿐이다.
- 미래 예약 날짜 수에는 고정 상한을 두지 않는다.
