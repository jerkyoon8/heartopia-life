# PRD: 고래낙하 협곡 동물 위치 지정

## 1. Summary

### Problem

관리자가 동물 데이터를 추가할 때 `고래낙하 협곡`을 위치로 명확히 선택할 수 없고, 해당 위치의 동물이 두 번째 인터랙티브 지도에 나타나지 않아 지도에서 핀을 배치할 수 없다.

### Proposed Solution

동물 관리자 입력 모달에 `고래낙하 협곡` 위치 선택지를 제공한다. 해당 위치로 저장된 동물은 두 번째 지도에서 관리자에게 미배치 항목으로 노출하고, 관리자가 지도를 클릭해 그 지도에 핀을 저장할 수 있게 한다.

### Success Criteria

- 관리자가 동물 추가·수정 모달에서 `고래낙하 협곡`을 선택할 수 있다.
- `고래낙하 협곡` 동물은 두 번째 지도에서만 동물 목록에 나타난다.
- 관리자가 두 번째 지도에서 해당 동물을 선택하고 클릭해 핀을 저장할 수 있다.
- 저장된 핀은 두 번째 지도에만 표시된다.
- 고래낙하 협곡 지도를 처음 열면 전체 카테고리·핀·구역 표시가 켜져 있다.

## 2. Users And Use Cases

### Primary Users

- 동물 도감과 인터랙티브 지도 데이터를 관리하는 관리자
- 인터랙티브 지도에서 동물 위치를 확인하는 일반 사용자

### User Stories

- As a 관리자, I want to 동물의 위치를 고래낙하 협곡으로 저장하고 그 지도에 핀을 배치, so that 실제 출현 지도를 정확히 관리할 수 있다.
- As a 사용자, I want to 고래낙하 협곡 지도에서 그곳에 속한 동물 핀만 확인, so that 지도별 위치를 혼동하지 않을 수 있다.

## 3. Functional Scope

### In Scope

- 동물 추가·수정 모달의 위치 입력을 명시적 선택 방식으로 변경
- `고래낙하 협곡` 위치의 동물을 내부 지도 키 `second`에 연결
- 두 번째 지도 선택 버튼의 표시명을 `고래낙하 협곡`으로 변경
- 고래낙하 협곡 지도의 초기 표시 상태를 `전체 표시`로 설정
- 두 번째 지도의 관리자 동물 핀 배치와 일반 사용자 표시
- 동물 지도 분리 동작의 회귀 테스트

### Out Of Scope

- 물고기·곤충·새·채집물·주민의 지도 귀속 규칙 변경
- 이벤트명 `고래 탐사 시즌` 변경
- 내부 지도 키 `second` 변경
- 새로운 동물 데이터인 돌고래 자체 추가
- 지도 이미지나 구역 데이터 변경

## 4. Acceptance Criteria

- 동물 관리자 모달에서 기존 기본 지도 위치와 `고래낙하 협곡`을 선택할 수 있다.
- 기존 동물 수정 시 저장된 위치가 선택 상태로 복원된다.
- `/wiki/map?mapKey=second`의 동물 API 응답에는 위치가 `고래낙하 협곡`인 동물만 포함된다.
- 기본 지도 동물 API 응답에는 `고래낙하 협곡` 동물이 포함되지 않는다.
- 관리자가 두 번째 지도에서 미배치 동물의 위치 지정 버튼을 누르고 지도를 클릭하면 `map_key=second` 핀이 저장된다.
- 일반 사용자는 핀 배치·변경 버튼을 볼 수 없으며 저장 API의 기존 관리자 권한 정책이 유지된다.
- 기존 기본 지도 동물 핀 배치와 표시는 회귀하지 않는다.
- 고래낙하 협곡 지도는 첫 진입 시 모든 카테고리·핀·구역을 표시하고, 이후 사용자가 개별적으로 끌 수 있다.

## 5. Constraints

- Tech: Spring Boot, Thymeleaf, MyBatis, Vanilla JavaScript, 기존 `map_key` 기반 지도 분리 구조 사용
- Time: 이번 변경은 동물 범위로 제한
- Data: 정식 위치명은 `고래낙하 협곡`, 이벤트명은 `고래 탐사 시즌`
- External Dependencies: 없음

## 6. Risks

- 위치 문자열 오타로 지도 귀속이 달라질 수 있음: 관리자 입력을 선택형으로 제한하고 서버에서 동일한 상수를 사용한다.
- 기존 API가 `mapKey`를 무시함: 동물 API에서만 명시적으로 정규화하고 필터링한다.
- 다른 종류까지 의도치 않게 필터링될 수 있음: 이번 변경은 동물 엔드포인트와 동물 모달에만 제한한다.
