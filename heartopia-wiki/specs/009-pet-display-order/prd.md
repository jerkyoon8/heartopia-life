# PRD: 반려동물 표시 순서 조정

## 1. Summary

### Problem

새 반려동물은 목록 오른쪽 끝에만 추가되며, 사용자가 자주 확인하는 반려동물을 원하는 위치로 옮길 수 없다.

### Proposed Solution

선택한 반려동물을 한 칸씩 왼쪽 또는 오른쪽으로 이동하는 버튼을 제공하고, 변경된 배열 순서를 기존 로컬 저장 및 로그인 동기화 데이터에 그대로 저장한다.

### Success Criteria

- 선택한 반려동물을 목록에서 왼쪽 또는 오른쪽으로 한 칸 이동할 수 있다.
- 첫 항목의 왼쪽 이동과 마지막 항목의 오른쪽 이동은 비활성화된다.
- 변경된 순서가 새로고침 후에도 유지된다.

## 2. Users And Use Cases

### Primary Users

- 여러 반려동물의 먹이 기록을 관리하는 사용자

### User Stories

- As a 반려동물 기록 사용자, I want to 반려동물의 표시 순서를 좌우로 조정하고, so that 자주 보는 반려동물을 앞쪽에 둘 수 있다.

## 3. Functional Scope

### In Scope

- 선택된 반려동물의 한 칸 왼쪽 이동
- 선택된 반려동물의 한 칸 오른쪽 이동
- 목록 경계에 따른 이동 버튼 비활성화
- 로컬 저장과 로그인 동기화 저장을 통한 순서 유지
- 키보드와 보조기기에서 이해할 수 있는 버튼 이름

### Out Of Scope

- 드래그 앤 드롭 정렬
- 여러 칸을 한 번에 이동하거나 임의 순번을 입력하는 기능
- 호텔 입실 여부나 종류를 기준으로 하는 자동 정렬
- DB 스키마 또는 API 형식 변경

## 4. Acceptance Criteria

- 반려동물이 두 마리 이상일 때 선택 상세 영역에 좌우 이동 버튼이 표시된다.
- 이동 후 선택 상태는 이동한 반려동물에 유지된다.
- 이동할 수 없는 방향의 버튼은 비활성화된다.
- 이동 직후 화면 목록이 새 순서로 갱신되고 기존 저장 함수가 호출된다.
- 반려동물이 없거나 하나뿐일 때 오류가 발생하지 않는다.

## 5. Constraints

- Tech: 기존 Thymeleaf 템플릿의 Vanilla JavaScript 및 `state.pets` 배열 사용
- Time: 현재 작업에서 구현 및 회귀 테스트 완료
- Data: 기존 JSON 배열 순서를 표시 순서로 사용
- External Dependencies: 없음

## 6. Risks

- 빠르게 연속 이동할 때 서버 저장 순서가 뒤섞일 수 있음: 기존 직렬 `saveQueue`를 재사용한다.
- 모바일에서 액션 버튼이 많아질 수 있음: 짧은 아이콘·텍스트 버튼과 기존 줄바꿈 레이아웃을 사용한다.

## 7. Open Questions

- 없음. 사용자가 요청한 좌우 한 칸 이동으로 범위가 명확하고 기존 배열 저장 구조가 순서를 보존한다.
