# Plan: 도감 날씨 상시 포함 및 레벨 빠른 선택

## Current code

- `fish.html`이 UI 기준이며 `bug.html`, `bird.html`도 같은 필터 구조를 쓴다.
- `wiki-filter.js`에서 날씨는 단일 선택 부분 문자열 비교, 레벨은 다중 체크 정확 일치로 처리한다.
- 시간대의 `상시 포함`은 별도 체크박스와 초기화 로직을 사용한다.

## Approach

1. 세 템플릿의 날씨 선택 옆에 체크박스를 추가한다.
2. 세 레벨 드롭다운에 `Lv.1~10 선택` 버튼을 추가한다.
3. 공통 스크립트에서 버튼이 있는 경우에만 1~10 체크 상태를 일괄 갱신한다.
4. 공통 스크립트에서 날씨 필터가 일반 기상값일 때 `상시`를 선택적으로 포함한다.
5. 초기화 상태와 카드·표 필터 결과를 테스트한다.

## Risks and verification

- `only-무지개`는 기존 정확 일치 분기를 유지한다.
- 새 DOM 요소가 없는 다른 도감 페이지는 영향을 받지 않도록 null 검사한다.
- Node 필터 테스트와 템플릿 테스트를 실행한다.
