# Plan: 도감 날씨 상시 포함 및 레벨 빠른 선택

## Current code

- `fish.html`이 UI 기준이며 `bug.html`, `bird.html`도 같은 필터 구조를 쓴다.
- `wiki-filter.js`에서 날씨는 단일 선택 부분 문자열 비교, 레벨은 다중 체크 정확 일치로 처리한다. 운영 장애는 1년 캐시되는 JS URL을 바꾸지 않아 발생했다.
- 시간대의 `상시 포함`은 별도 체크박스와 초기화 로직을 사용한다.

## Approach

1. 세 템플릿의 날씨 필터를 기존 레벨과 같은 다중 체크 드롭다운으로 바꾸고 `상시 포함`은 유지한다.
2. 레벨 드롭다운의 고정 1~10 버튼을 시작·끝 입력과 범위 선택 버튼으로 바꾼다.
3. 공통 스크립트에서 날씨 합집합 및 레벨 범위의 유효성·선택을 처리한다.
4. 세 도감 JS와 공통 CSS URL 버전을 올려 캐시된 파일을 교체한다.
5. 단위·템플릿·실제 로컬 서버 브라우저 테스트로 필터와 초기화를 검증한다.

## Risks and verification

- 중복된 `only-무지개` 선택지와 분기를 제거하고 남은 날씨 선택의 합집합을 확인한다.
- 새 DOM 요소가 없는 다른 도감 페이지는 영향을 받지 않도록 null 검사한다.
- Node 필터 테스트와 템플릿 테스트를 실행한다.
