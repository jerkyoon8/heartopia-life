# Feature Spec: 도감 날씨 상시 포함 및 레벨 빠른 선택

## Source

- [PRD](prd.md)
- `../principles.md`

## Scenarios

1. 맑음 선택 후 `상시 포함`을 켜면 날씨에 `해`가 포함된 항목과 정확히 `상시`인 항목을 본다. 끄면 맑음 항목만 본다.
2. 비·무지개도 같은 규칙을 따른다. `무지개만 출력`은 정확히 `무지개`인 항목만 본다.
3. `Lv.1~10 선택`을 누르면 1~10 체크박스만 켜지고 11~14는 꺼진다. 이어서 수동으로 체크를 바꿀 수 있다.
4. 초기화하면 모든 레벨·모든 날씨, 날씨 `상시 포함` 체크 상태로 돌아간다.

## Functional Requirements

- FR-001: 날씨 체크박스는 특정 기상 선택에만 적용한다.
- FR-002: 날씨 `상시`는 공백을 제외하고 정확 일치로 판단한다.
- FR-003: 레벨 빠른 선택은 기존 다중 선택 상태를 사용해 카드·표를 동시에 갱신한다.
- FR-004: 새 UI가 없는 페이지의 공통 필터 동작은 그대로 둔다.

## Data / Interface

- 기존 `data-weather`, `data-level`만 사용한다. 저장 데이터와 API 변경은 없다.
- 빠른 선택은 클라이언트에서만 동작하며 선택 상태는 새로고침 시 유지하지 않는다.
