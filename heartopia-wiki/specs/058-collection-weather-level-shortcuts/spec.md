# Feature Spec: 도감 날씨 상시 포함 및 레벨 빠른 선택

## Source

- [PRD](prd.md)
- `../principles.md`

## Scenarios

1. 맑음과 비를 함께 체크하면 둘 중 하나에 해당하는 항목을 본다. `상시 포함`을 켜면 정확히 `상시`인 항목도 본다.
2. `상시` 체크는 단독 또는 다른 날씨와 함께 사용할 수 있다. `무지개만 출력` 선택지는 없다.
3. 시작 3, 끝 8을 입력해 범위 선택을 누르면 레벨 3~8 체크박스만 켜진다. 이어서 수동으로 체크를 바꿀 수 있다.
4. 초기화하면 모든 레벨·모든 날씨, 날씨 `상시 포함` 체크 상태로 돌아간다.

## Functional Requirements

- FR-001: 여러 날씨 체크는 합집합으로 적용한다. `상시 포함`은 일반 기상 선택이 하나 이상 있을 때 정확히 `상시`인 항목을 더한다.
- FR-002: 날씨 `상시`는 공백을 제외하고 정확 일치로 판단한다.
- FR-003: 레벨 범위 선택은 양 끝을 포함하며 기존 다중 선택 상태를 사용해 카드·표를 동시에 갱신한다.
- FR-004: 새 UI가 없는 페이지의 공통 필터 동작은 그대로 둔다.
- FR-005: 유효하지 않은 범위는 적용하지 않고 입력 옆에 오류를 표시한다.
- FR-006: JS와 CSS URL 버전을 올려 캐시된 이전 코드 대신 새 코드를 받게 한다.

## Data / Interface

- 기존 `data-weather`, `data-level`만 사용한다. 저장 데이터와 API 변경은 없다.
- 범위 선택은 클라이언트에서만 동작하며 선택 상태는 새로고침 시 유지하지 않는다.
